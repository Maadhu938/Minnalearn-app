1.) とおりに

This means to copy something exactly as shown/seen etc.

1.1 Usage wit a verb: V1 とおりに、V2

わたしが　やる　とおりに、やって　ください。 Please do as I do.

みた　とおりに、はなして　ください。　Please tell us what you saw as you saw it.

#
1.2 Usage with a noun:Nのとおりに、V

せんの　とおりに、かみを　きって　ください。　Please cut the paper along the line.

2.) あとで

This pattern is used to describe an occurrence happening after an event or action.

#
2.1 Usage with a verb: た-formあとで, V

あたらしのを　かった　あとで、なくした　とけいが　みつかりました。After I bought a new watch, I found the one I'd lost.

#
2.2 Usage with a noun: Nのあとで, V

しごとの　あとで、のみに　いきませんか？Shall we have a drink after work?

3.) で

This pattern is used to describe an action being accompanied by another action:

しょうゆを　つけて　たべます。　We eat it with soy sauce (lit.: using soy sauce).

しょうゆを　つけないで　たべます。　We eat it without soy sauce.
